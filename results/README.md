# SQL 실행 결과 저장 안내

Adminer에서 `queries/queries.sql`의 쿼리를 번호별로 실행하고, SQL과 결과 열·행이 함께 보이도록 캡처합니다. 파일명은 모두 소문자와 두 자리 번호를 사용합니다.

Query 16과 17은 `START TRANSACTION`부터 `ROLLBACK`까지 블록 전체를 실행하세요. Query 18은 인덱스 생성 성공 메시지, Query 19는 `EXPLAIN` 결과 표를 캡처합니다.

## 권장 캡처 절차

1. Query 01~17을 차례대로 실행하고 캡처합니다.
2. Query 18은 한 번만 실행합니다.
3. Query 19를 실행해 인덱스 후보를 확인합니다.
4. 다시 처음부터 실행하려면 `schema.sql → seed.sql → queries.sql` 순서로 초기화합니다.
5. 모든 PNG를 이 `results` 폴더에 저장합니다.

실행 결과는 PC의 MySQL 상태를 직접 증명하는 자료이므로 저장소에는 빈 예시 이미지를 만들지 않았습니다.
